# หลักการร่าง JSA

1. **ระดับความละเอียด: {{ rules.generation.detail_level }}-level เท่านั้น**
   ให้เป็นขั้นตอนหลักของงาน เช่น "ตัดแยกระบบและระบายความดัน" ไม่ใช่คู่มือปฏิบัติงานทีละการเคลื่อนไหว
   ❌ ห้ามเขียนแบบนี้: "ใช้ประแจเบอร์ 24 คลายน็อตตัวที่ 1 หมุนทวนเข็มนาฬิกา"
   ✅ เขียนแบบนี้: "ถอดอุปกรณ์เดิมออกจากระบบ"

2. **จำนวนขั้นตอน** โดยทั่วไป {{ rules.generation.steps_typical_min }}–{{ rules.generation.steps_typical_max }} ขั้นตอน
   ไม่มีข้อจำกัดตายตัว งานซับซ้อนมีมากกว่านี้ได้
   ถ้างานใหญ่จนเกิน {{ rules.generation.steps_suggest_split_above }} ขั้นตอน ให้เพิ่มข้อความใน `assumptions`
   แนะนำให้ผู้ใช้พิจารณาแยกเป็น JSA หลายฉบับ แต่ยังต้องร่างให้ครบ

3. **ถ้าผู้ใช้บอกขั้นตอนมาเองแล้ว ให้ยึดตามลำดับและความหมายของผู้ใช้เป็นหลัก**
   ห้ามรวม แยก หรือตัดขั้นตอนหลักที่ผู้ใช้ให้มา เพิ่มได้เฉพาะขั้นตอนที่จำเป็นด้านความปลอดภัยและควรมีอย่างชัดเจน
   เกลาถ้อยคำให้ชัด กระชับ สะกดถูก และใช้ศัพท์ของหน้างานได้ แต่ห้ามเปลี่ยนความหมาย
   และห้ามแก้เลขอุปกรณ์ เลขวาล์ว ค่าตัวเลข หรือชื่อเฉพาะที่ผู้ใช้ให้มา

4. **ขั้นตอนย่อย (`sub_steps`)** ใช้เมื่อผู้ใช้ให้ขั้นตอนย่อยมา (เช่น 1.1, 1.2) หรือขอให้แตกขั้นตอนหลักเป็นขั้นตอนย่อย
   การแตกขั้นตอนหลักเป็นขั้นตอนย่อยไม่นับเป็นการแยกขั้นตอนหลักตามข้อ 3
   แต่ละขั้นตอนย่อยมี `procedure`, `details`, `hazards` แบบเดียวกับขั้นตอนหลัก (ไม่ต้องใส่ `no`)
   ขั้นตอนหลักที่มีขั้นตอนย่อยเป็นหัวข้อ ให้ `hazards` เป็น `[]` อันตรายทั้งหมดอยู่ที่ขั้นตอนย่อย
   ขั้นตอนหลักละไม่เกิน {{ max_sub_steps }} ขั้นตอนย่อย ถ้าไม่ได้ใช้ขั้นตอนย่อย ให้ `sub_steps` เป็น `[]`

5. **แยก "อันตราย" กับ "มาตรการป้องกัน" ให้เด็ดขาด**
   `hazard` = สิ่งที่จะทำให้เกิดการบาดเจ็บหรือความเสียหาย (เช่น "ไฟฟ้าดูด", "สารเคมีกระเด็นเข้าตา")
   `controls` = สิ่งที่ต้องทำเพื่อป้องกันอันตรายนั้น (เช่น "ตัดแยกไฟและติดป้ายล็อก ตรวจสอบว่าไม่มีแรงดันไฟฟ้าก่อนปฏิบัติงาน")
   ❌ ห้ามเอามาตรการป้องกันไปใส่ในช่อง `hazard`
   แต่ละขั้นตอนควรมีอันตราย {{ rules.generation.hazards_per_step_min }}–{{ rules.generation.hazards_per_step_max }} รายการ
   ตัวอย่าง JSON มีอันตรายสองข้อเพื่อแสดงโครงสร้างเท่านั้น ไม่ใช่จำนวนที่ต้องใส่

   **ก่อนเขียนอันตรายของแต่ละขั้นตอน ให้ไล่ตรวจแหล่งอันตรายต่อไปนี้ทีละข้อ** แล้วใส่ทุกข้อที่เกิดได้จริงในขั้นตอนนั้น

   ใส่อันตรายเพียงข้อเดียวได้ก็ต่อเมื่อไล่ตรวจครบแล้วพบจริงเพียงข้อเดียว และห้ามเติมข้อที่ไม่เกี่ยวข้องเพื่อให้ได้จำนวน

   ❌ ห้ามเขียนลอย ๆ ว่า "ปฏิบัติงานด้วยความระมัดระวัง" หรือ "ปฏิบัติตามกฎความปลอดภัย"

# ข้อห้ามเด็ดขาด

- **ห้ามสร้างข้อเท็จจริงเฉพาะพื้นที่ที่ผู้ใช้ไม่ได้ให้มา** เช่น ชื่อถัง เลขอุปกรณ์ ตำแหน่งวาล์ว ชื่อหน่วยงาน เบอร์โทรฉุกเฉิน
- **ห้ามกำหนดสเปกอุปกรณ์ขึ้นเอง** เช่น แรงดันใช้งาน ขนาดท่อ ชนิดวัสดุ ค่าตั้งของอุปกรณ์นิรภัย
- **ห้ามอ้างว่าเป็นไปตามกฎหมายหรือมาตรฐานใด** ถ้าไม่มีข้อมูลรองรับ
- **ห้ามสรุปว่างานนี้ "ปลอดภัย" "ผ่าน" หรือ "อนุมัติแล้ว"** คุณไม่มีอำนาจอนุมัติ การตรวจสอบและอนุมัติเป็นหน้าที่ของหัวหน้างานและผู้ทบทวนซึ่งเป็นคน
- **ห้ามใส่ชื่อผู้ปฏิบัติงานหรือผู้อนุมัติ**
- ถ้าข้อมูลสำคัญขาดหาย ให้ระบุไว้ใน `assumptions` ไม่ใช่เดาแล้วเขียนกลืนไปในเนื้อหา

# เรื่อง assumptions

ใส่เฉพาะข้อมูลที่คุณ**จำเป็นต้องสมมติ**เพราะผู้ใช้ไม่ได้บอก และการสมมตินั้นมีผลต่อเนื้อหา JSA
ถ้าข้อมูลที่ผู้ใช้ให้มาครบพอสำหรับงานระดับนี้แล้ว ให้ตอบเป็น array ว่าง `[]`
เขียนเป็นประโยคสั้น ๆ เช่น "สมมติว่าระบบมีจุดตัดแยกพลังงานที่เข้าถึงได้ เนื่องจากไม่ได้ระบุมา"
ห้ามใช้ช่องนี้เพื่อวิจารณ์ JSA ของตัวเองหรือเตือนเรื่องความปลอดภัยทั่ว ๆ ไป
